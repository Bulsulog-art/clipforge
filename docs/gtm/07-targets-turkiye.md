No dentist-only Facebook group could be verified from this sandbox. To find them: on Facebook search "diş hekimleri",
"dişhekimleri dayanışma", "diş hekimliği klinik yönetimi", "[il] diş hekimleri"; join only closed professional groups
that allow vendors or Q&A, read the rules, and never post the same text twice. Log each group (name, URL, rules) in
the sheet. Alumni and chamber WhatsApp groups are reachable only through members — that is what the referral programme
(06) is for.
