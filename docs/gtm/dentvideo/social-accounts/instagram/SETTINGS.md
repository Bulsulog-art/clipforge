# Settings checklist

Menu names change between app versions. If one is missing, use the search box in Settings.

## Security (do these first)
- [ ] **Two-factor authentication:** Accounts Center → Password and security → Two-factor authentication →
      **Authentication app**. Use an authenticator app, not SMS: SMS ties the account to one person's SIM.
- [ ] Save the **backup codes** in the owner's password manager. Do not put them in the repo, and do not
      paste them into chat.
- [ ] The password is unique and generated, and stored in the same password manager.
- [ ] The login email is **hello@dentvideo.com**. Confirm the verification email arrives.
- [ ] If Instagram insists on a phone number, use a founder's number. It is not shown on the profile.
- [ ] Accounts Center → Password and security → **Login alerts** on (email to hello@).

## Account type and contact
- [ ] Settings → Account type and tools → **Switch to professional account → Business**.
      Category: **Yazılım** (Software). Choose "Display category" ON.
- [ ] Contact options: **email only** (hello@dentvideo.com). Phone **off**, WhatsApp **off**, address **off**.
- [ ] No action button.

## Privacy and safety
- [ ] **Account privacy: Public.** A Business account cannot be private, and clinics must be able to see
      the grid before a DM.
- [ ] Tags and mentions → **Manually approve tags** ON. Mentions from: Everyone.
- [ ] Hidden words → **Hide comments** ON, **Advanced comment filtering** ON.
- [ ] Messages → message requests from everyone (clinics will DM). Turn on Instagram's **Saved replies**
      only for factual answers taken from the site.
- [ ] **Sharing and remixing:** Allow remixing **OFF** (the samples carry a sample-clinic badge that
      should not be cut out).
- [ ] Activity status: off (optional).

## Branded content
- [ ] **Leave branded-content tools unused.** DentVideo pays no creators and has no partners. Do not add a
      "Paid partnership" label to our own posts, and do not approve partner requests.
- [ ] If a partnership is ever approved by the owner: Settings → Business tools and controls → Branded
      content → require approval of partners. Not now.

## Each post (posting flow)
- [ ] Advanced settings → **AI label ON** for Reels 02/04/06 and carousel 08 (synthetic narration).
- [ ] Location: none. Tag people/products: none.
- [ ] Share to Facebook: **off** unless the Facebook Page exists and someone answers comments there.

## Meta Business Suite / Facebook Page linking
- [ ] Only if a **DentVideo Facebook Page** exists (or the owner decides to create one): Instagram →
      Accounts Center → Accounts → **Add accounts** → the Facebook account that admins the Page; then in
      **business.facebook.com** → Settings → Instagram accounts → **Connect** → sign in to @<handle>.
- [ ] In Business Suite set the Business name to **DentVideo** and the legal entity to
      **"BLS AI AUTOMATION" DOO PODGORICA**, contact hello@dentvideo.com.
- [ ] Do **not** add a payment method, do not boost a post, and do not start Meta Verified (it is paid).
      Spending needs the owner's approval.
- [ ] If there is no Page yet, skip this section. The Instagram account works without it.
